# Лабораторные работы по дисциплине «Хранилища данных»

Выполнил: **Колесников**, группа **223-322**.

Репозиторий содержит материалы четырёх лабораторных работ: модель данных
Data Vault (вариант 6), работу с системой контроля версий Git, лабораторную
работу по MongoDB и лабораторную работу по Neo4j.

## Структура репозитория

| Каталог | Содержание |
|---|---|
| `lab2_datavault/` | Лабораторная работа «Проектирование хранилища данных (Data Vault)», вариант 6 — «Система учебного графика дисциплин факультета». Две модели: 3НФ (`sql/01_schema_3nf.sql`) и Data Vault 2.0 (`sql/02_schema_datavault.sql`), тестовые данные (`sql/03_data.sql`), типовые запросы (`sql/04_queries.sql`), схемы в `diagrams/`, журналы выполнения в `outputs/`. |
| `lab_mongodb/` | Лабораторная работа №1 по MongoDB: `scripts/mongo_lab1.js` — все команды работы, `outputs/` — протоколы сессии, `screenshots/` — скриншоты. |
| `lab_neo4j/` | Лабораторная работа №1 по Neo4j: `cypher/` — запросы Cypher (примеры лекции и социальный граф персонажей), `outputs/` — протоколы, `screenshots/` — скриншоты. |
| `docs/` | Итоговый отчёт по всем лабораторным работам (файл Word). |

## Краткое описание работ

1. **Data Vault (вариант 6).** СУБД PostgreSQL 18.4. В одной базе
   `faculty_schedule` созданы две схемы: `nf3` — нормализованная модель в
   третьей нормальной форме (кафедры, корпуса, аудитории, направления
   подготовки, группы, преподаватели, дисциплины, занятия) и `dv` — модель
   Data Vault 2.0 (6 хабов, 4 ссылки, 7 сателлитов). Сверка двух моделей
   показывает эквивалентность результатов.

2. **Git.** Локальный репозиторий с кодом предыдущей лабораторной работы,
   перенесённый в удалённый репозиторий GitHub.

3. **MongoDB.** Установка сервера и клиента, создание базы данных и
   коллекций, добавление документов, выборки с условиями, работа с вложенными
   документами и массивами, изменение и удаление документов, коллекций и баз
   данных.

4. **Neo4j.** Практические примеры Cypher (CREATE, MATCH, WHERE, SET, REMOVE,
   DELETE, связи) и социальный граф по материалу «Персонажи»: 12 персонажей и
   3 группы, 37 связей.
